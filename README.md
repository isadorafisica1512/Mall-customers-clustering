# Mall Customers – Customer Segmentation with K-Means Clustering

## Project Overview

This project explores customer segmentation using unsupervised machine learning techniques, with the objective of identifying distinct customer profiles based on annual income and spending behavior.

Using the Mall Customers dataset, I applied the K-Means clustering algorithm to identify groups of customers with similar characteristics. The analysis goes beyond general customer segmentation by examining spending patterns across six demographic groups, combining gender and age categories.

The main goal is to transform customer data into actionable business insights that can support targeted marketing strategies, customer engagement, and business decision-making.

## Objectives

- Explore customer demographic and spending characteristics.
- Identify distinct customer segments using K-Means clustering.
- Analyze the relationship between annual income and spending scores.
- Compare customer profiles across gender and age groups.
- Identify potential business opportunities for each customer segment.
- Develop data-driven marketing recommendations based on clustering results.

## Dataset

The project uses the **Mall Customers Dataset**, which contains demographic and behavioral information about mall customers.

The main variables used in the analysis are:

| Variable | Description |
|---|---|
| CustomerID | Unique customer identifier |
| Gender | Customer gender |
| Age | Customer age |
| Annual Income (k$) | Customer's annual income in thousands of dollars |
| Spending Score (1–100) | Score assigned by the mall based on customer spending behavior and purchasing patterns |

Annual Income and Spending Score were selected as the primary features for customer segmentation.
